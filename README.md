# استبيان الحوكمة والتشغيل للمجموعة والمطاعم

هذا استبيان عربي لجمع المعلومات الأولية اللازمة لتصميم نظام الحوكمة والتشغيل للمجموعة والمطاعم في الصين.

## طريقة الاستخدام على الهاتف

1. افتح الرابط باستخدام Safari أو Chrome.
2. أجب عن الأسئلة الاختيارية.
3. اضغط «إكمال ومشاركة الإجابات».
4. أرسل ملف الإجابات الناتج عبر واتساب أو البريد الإلكتروني.

لا يتم رفع إجابات المستجيب إلى هذا المستودع. يتم إنشاء ملف الإجابات على جهازه فقط، ثم يختار هو طريقة مشاركته.
